序

机の上を、整える。道具は束ねて、ひとつの庭にする。

ここには、わたしの macOS の環境がある。設定は束にして、Stow で家に結ぶ。一行で入り、同じ手順で、何度でも元に戻せる。

迷わない、という優しさのために。

巻之二束

七つの束は、輪になって名を連ねる。

署名を押すと、その束の頁へ

Stow で家へ結ぶと

家に
~/.zshrc
実体は
dotfiles/packages/zsh/.zshrc

家に置かれるのは、束の中のファイルへの「結び目」（symlink）。直すのは、束の中だけでよい。

庵の手引問い二十

跋検証のこと

入れ方は、そのまま信じず、毎回たしかめる。

macOS
入れ方を、まっさらな環境で通し直す
shell
shellcheck でスクリプトを見張る
整形
shfmt と stylua で形をそろえる
依存
dependabot が見守る

docs や文書だけの変更では、動かさない。
